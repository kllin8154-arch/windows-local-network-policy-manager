# UI 视觉规范：American Retro Network Console

本项目界面采用美式复古海报感的深色网络控制台风格。后续修改 UI 时，不应重新引入默认 WinForms 蓝白配色。

## 核心配色

| Token | Hex | 用途 |
| --- | --- | --- |
| Background | `#1A1A1A` | 主背景、空白区、次级按钮背景 |
| Accent | `#CDA47B` | 主标题、表头、关键识别入口、已连接/正常状态文字 |
| AccentStrong | `#9F4125` | 主操作、强调条、危险/冲突状态 |
| SurfaceAlt | `#382020` | 次级面板、日志区、已接管状态、危险按钮底色 |
| WarmText | `#F4E4D1` | 深色背景上的正文 |
| MutedText | `#BE9E80` | 说明文字、次级信息 |
| Surface | `#2B1F1D` | 表格、输入框、卡片背景 |
| Border | `#5C3D32` | 细边框和分隔线 |

前四个颜色来自当前设计参考图，后四个仅用于解决深色界面的文字层级和可读性。

## 设计原则

1. **深色底 + 暖色信息层级**  
   主背景使用 `#1A1A1A`，避免白色大面积面板。

2. **米色用于“可阅读的重要信息”**  
   `#CDA47B` 主要用于标题、表头、自动识别入口和正常状态，不要把所有按钮都填成米色。

3. **砖红用于“动作与风险”**  
   `#9F4125` 用于应用策略、接管现有路由、冲突提示和少量视觉锚点。

4. **酒红用于“已接管/次级容器”**  
   `#382020` 适合日志、已管理策略和次级操作。

5. **不依赖传统红黄绿状态色**  
   状态仍通过文字说明，同时在同一复古色系中表达：
   - 已应用 / 已接管：酒红底 + 米色字
   - 未应用 / 未管理：米色底 + 黑字
   - 冲突 / 错误：砖红底 + 暖白字
   - 禁用 / 不可用：深色底 + 暗米色字

6. **普通用户优先**  
   UI 首屏应先回答“现在网络是怎么走的”，然后才让用户新增、修改、应用规则。不要要求用户先理解 InterfaceIndex、RouteMetric 等 Windows 网络术语。

## 主窗口结构

- 顶部品牌区：
  - 小号英文眉题 `LOCAL NETWORK POLICY`
  - 中文主标题
  - “自动识别 → 用户决定是否接管”的安全边界说明
  - 右侧显示当前识别结论
- 概览卡：
  - 规则状态
  - 已连接实体网卡
  - 当前默认出口
  - 待处理现有策略
  - “待处理现有策略”卡片本身可点击进入识别窗口
- 工具栏：
  - 第一入口固定为“识别当前策略”
  - 保留新增、应用全部、刷新、规则备份与安全导入
  - 同一行提供规则搜索和状态过滤，避免把常用动作堆成大量按钮
- 主工作区：
  - 左侧为规则表格
  - 右侧为所选规则详情与快捷操作
  - 两侧使用 SplitContainer，并设置最小宽度，避免窗口缩放和 DPI 变化时挤坏布局
- 右侧快捷操作：
  - 应用 / 诊断 / 修改 / 复制详情 / 撤销 / 删除
  - 危险动作保持酒红/砖红层级，并保留确认
- 底部日志：
  - 酒红底
  - 米色等宽字体
  - 可一键折叠，避免长期占据主工作区
- 状态栏：
  - 显示管理员/只读模式
  - 最后刷新时间
  - 当前筛选后的规则数量
  - 15 秒自动刷新开关

## 自动识别窗口

自动识别窗口按三个视角组织：

1. **特定路由**：用户真正需要决定是否导入/接管的策略。
2. **网卡概览**：当前网卡、IPv4、默认网关与硬件 GUID。
3. **代理绕过**：Windows ProxyOverride 当前状态。

自动识别始终只读。已有策略只有用户点击“导入并接管”后，程序才获得撤销该路由的权限。

特定路由页支持 Ctrl / Shift 多选，便于一次导入多条已有路由。未管理路由应优先展示；“导出诊断快照”用于把当前网卡、默认路由、特定路由和代理绕过完整保存为 JSON，便于现场排障或交给 AI/MCP 分析。

## 后续 UI 修改要求

任何 AI 或开发者修改界面前，应先阅读本文件和 `NetworkPolicyManager/README.md`。新增窗口应复用脚本中的 `$script:Theme`、`New-UiButton`、`Initialize-GridTheme` 与 `Set-UiInputTheme`，不要在各窗口重复硬编码另一套颜色。
