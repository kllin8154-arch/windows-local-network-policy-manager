Windows Local Network Policy Manager 0.2.0 Preview x64

这是免安装验证包。

使用：
1. 解压 ZIP 到任意目录。
2. 双击“本地网络策略管理器.exe”。
3. UAC 选择“是”。
4. 第一轮先查看自动识别、界面、搜索/筛选/诊断等，不要立即点击“应用全部”。
5. 将运行截图、异常提示或导出的诊断快照返回给开发者。

注意：
- EXE 与 NetworkPolicyManager 文件夹必须保持在同一目录。
- 自动识别是只读的。
- 真正点击“应用/撤销”才会修改 Windows 精确路由或代理绕过。
- 本预览包为 Windows x64。
