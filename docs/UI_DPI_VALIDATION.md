# UI / DPI 验证矩阵

WinForms 主窗体与主要弹窗统一设置 AutoScaleMode=Dpi。

GitHub Windows Runner 自动验证：

- PowerShell parse；
- UI Smoke Test；
- 生成 ui-smoke-test.png；
- 主窗体可以完整显示并关闭。

Runner 的系统显示缩放不能作为 125% / 150% / 175% 的可靠模拟，因此这些比例保留实机检查，不能用字体放大等方式冒充 DPI 测试。

## 实机矩阵

| DPI | 主窗体 | 自动识别 | 选路查询 | 安全中心 | 规则编辑器 |
| --- | --- | --- | --- | --- | --- |
| 100% | CI + 实机 | 检查 | 检查 | 检查 | 检查 |
| 125% | 实机 | 实机 | 实机 | 实机 | 实机 |
| 150% | 实机 | 实机 | 实机 | 实机 | 实机 |
| 175% | 实机 | 实机 | 实机 | 实机 | 实机 |

每个比例检查：

- 标题/按钮不被裁切；
- 表格列头可读；
- 搜索框、状态筛选、分组筛选不重叠；
- 安全中心底部按钮不超出窗口；
- 默认出口页能看到类型、网关、Route/Interface/Effective Metric；
- 选路解释器能看到网卡类型、下一跳和 Metric；
- Rule Editor 的分组/标签/网关控件不重叠；
- 文字不出现深色背景粘连或边缘截断。

如果某个 DPI 失败，只调整布局/AutoSize/Anchor/Dock，不应改变网络策略逻辑。
